# Little-endian fields toy corpus

This deliberately non-cryptographic example encodes unsigned 16-bit fields in
little-endian order. It exists only to exercise canonical values, explicit
lengths, multiple profiles, expected errors, and represented total-decoding
cases.

It is original project material and is not derived from an external protocol.
